## 1. Bugs confirmados (corrigir)

### P0 — `runtime/inference.py:377` retorno inconsistente no modo speculative
`generate(..., speculative_k>0)` retorna `self._generate_speculative(...)`, que retorna tupla `(str, stats)`. O caminho normal retorna `str`.
Quem chama `infer --speculative K` com painel recebe tupla onde espera string.
Fix mínimo: desembrulhar no caller ou padronizar para `str` + stats opcional via atributo.

### P1 — `engine/rwkv_engine.py:54` atribuição acidental
```python
self.n_embd = n_layer and n_embd
```
Funciona por acidente (`12 and 768 == 768`), quebra se `n_layer=0`. Trocar por `self.n_embd = n_embd`.

### P1 — `engine/rwkv_engine.py:58-59` `bos_id == eos_id == 0`
Geração nunca detecta EOS por id; parada só por `max_tokens`. Se o tokenizer RWKV usa 0 como BOS real, o `generate` filtra o prompt errado (`generated = [t ... if t not in (bos,eos)]` esvazia tudo). Definir ids reais ou `eos_id = None` + guarda no `generate`.

### P1 — `api/server.py:149-152` exceção no worker trava o SSE até timeout
`_blocking_stream` só põe `None` no fim normal ou `ClientDisconnected`. Qualquer outro erro mata a thread sem sinalizar → `_stream_sse` fica bloqueado em `out_q.get` até `TIMEOUT_SECS` (300 s).
Fix: `except Exception as e: out_q.put(e)` + `finally: out_q.put(None)` se ainda não pôs, e o consumidor emite `{"error": ...}`.

### P2 — `cli/main.py:76` `chat --weights` default quebra modo demo
Default é `"little_hawk_weights.npz"`. Sem o arquivo, `build_tokenizer_and_engine` faz `sys.exit(1)` em vez de cair no demo como `infer` (que tem default `None`) e a API (fallback demo). Trocar default para `None`.

### P2 — `cli/main.py:143,184` caminho `--no-panel` ignora `--speculative`
`handle_infer` no-panel e `handle_chat` nunca passam `speculative_k`. Passar o flag nos dois ou remover o flag do `chat` se intencional.

### P2 — `cli/main.py:204,209` `sys.argv` mutado para chamar transplant
Sobrescrever `sys.argv` global para reaproveitar `main()` do transplant é frágil (quebra testes/help). Chamar função com args explícitos.

## 3. Qualidade / dívida (não bloqueia, mas mascara verde)

### 3.1 `ruff.toml:8-16` exclui quase todo o core do lint
`engine/`, `runtime/`, `cli/main.py`, `transplants/`, `scripts/` fora do `ruff check/format` global. O "All checks passed" valida só `api/`, `utils/`, `tests/`. `CONTRIBUTING.md:17` confirma que é intencional ("estilo compacto"), mas então o CI nunca pega `F841/E741` no motor. ### 3.2 `Makefile:4` `check` cobre 7 arquivos, ignora o resto
Não compila `engine/rwkv_*`, `runtime/speculative.py`, `engine/speculative.py`, `tests/`. Trocar por `python -m compileall api cli engine runtime transplants utils tests`.

### 3.3 `Dockerfile:10` instala de `requirements.txt`, `pyproject` é ignorado
Duas fontes de deps para divergir. Instalar `pip install -e ".[api]"` ou gerar `requirements.txt` a partir do `pyproject`.

### 3.4 `runtime/inference.py:42` `rng = rng if ... else np.random` global
API já usa RNG por requisição no server, mas o fallback global no `Sampler.sample` mantém não-determinismo cruzado em uso direto. Default para `np.random.default_rng()` local.
